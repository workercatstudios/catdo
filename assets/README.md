# Brand assets

- `workercat-cat.png`: original WorkerCat mascot, also used by the website.
- `catdo-icon-source.png`: full-resolution CatDo launcher artwork.
- `com.workercat.catdo.png`: 512 × 512 desktop icon used by the installer and AppImage.

The CatDo icon was made with the built-in image generation tool using the
WorkerCat mascot as its reference, then resized for desktop packaging.
The original mascot is preserved.

Art direction: keep the round cat silhouette, pointed ears, closed diagonal
eyes, and curved mouth; use a charcoal cat on an ivory rounded tile with a
small sage completion badge. Keep the mark legible at launcher sizes, with
no lettering and transparency outside the tile.

These assets are included with CatDo under the repository license. No
trademark rights to the WorkerCat or CatDo names or branding are granted.
