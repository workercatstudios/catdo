# Brand assets

- `workercat-cat.png`: original WorkerCat mascot, also used by the website.
- `catdo-icon.svg`: CatDo icon source, drawn by hand as vector art.
- `com.workercat.catdo.png`: 512 × 512 icon rendered from the source, used by the
  desktop app, installer, AppImage and web app.

The icon follows the Kirakira UI character rules (kk.workercat.com): filled
shapes without outlines, happy arc eyes, pink blush, and Kirakira's palette. A
cream cat with pink inner ears sits on a navy rounded tile, with a pink
completion badge and two yellow sparkles. It keeps the original CatDo
silhouette: a round body, pointed ears and closed, smiling eyes. Keep the mark
legible at launcher sizes, with no lettering and transparency outside the tile.
To change it, edit the SVG and render the PNG at 512 × 512 with a transparent
background.
